# Quasar 🌌
### Machine Learning for Astronomical Object Classification

Quasar explores the use of machine learning to classify astronomical objects using data from the **Sloan Digital Sky Survey (SDSS) Data Release 17 (DR17)**.

The project investigates supervised and unsupervised learning techniques to analyse astronomical catalogue data and distinguish between **stars, galaxies, and quasars**.

## Objectives

- Explore and understand astronomical catalogue data through exploratory data analysis.
- Build and compare machine learning models for astronomical object classification.
- Investigate clustering techniques to identify patterns in the data.
- Examine the strengths and limitations of different classification approaches.

## Methods

**Supervised learning**
- Random Forest
- XGBoost
- Decision Tree
- Bagging Classifier
- LightGBM
- Gaussian Naive Bayes

**Unsupervised learning**
- K-Means
- BIRCH clustering

The workflow includes data exploration, preprocessing, model development, and performance evaluation.

## Tech Stack

- **Language:** Python
- **Data analysis:** Pandas, NumPy
- **Machine learning:** Scikit-learn, XGBoost, LightGBM
- **Visualisation:** Matplotlib, Seaborn
- **Environment:** Jupyter Notebook

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Tanisha6996/quasar.git
cd quasar
```

Install the required libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn xgboost lightgbm jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebook and run the cells to explore the analysis and modelling workflow.

## Research Context

This project reflects an interest in applying machine learning to astronomical data analysis. It provides a practical exploration of classification and clustering methods, with a focus on understanding how data-driven techniques can support the study of astronomical objects.
